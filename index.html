Panduan Deploy CBT (Apps Script + GitHub)

Langkah 1 — Buat Google Spreadsheet & Apps Script

Buka Google Sheets baru → klik menu Ekstensi > Apps Script → tempel kode Code.gs hasil dari prompt AI → klik Simpan.

Langkah 2 — Jalankan Setup Database Otomatis

Pilih fungsi setupDatabase di toolbar Apps Script lalu klik Jalankan (Run) dan berikan izin akses. Sheet Soal, Daftar_Siswa, dan Peserta beserta soal manual Anda akan terbentuk otomatis.

Langkah 3 — Deploy Backend sebagai Web App

Klik Terapkan (Deploy) > Deployment Baru > Aplikasi Web. Atur Jalankan sebagai: Saya, dan Yang memiliki akses: Siapa saja (Anyone). Salin URL Web App (.../exec).

Langkah 4 — Hosting Frontend di GitHub Pages

Tempel URL .../exec ke variabel API_URL di file index.html. Unggah ke repositori GitHub Anda → buka Settings > Pages → pilih branch main → simpan. Aplikasi CBT siap diakses dari HP, tablet, dan laptop!
